SaaS для автоматического обновления резюме на основе LinkedIn профиля.

ПРОБЛЕМА:
- IT специалист каждый месяц что-то делает (projects, skills, achievements)
- Резюме не обновляется месяцами
- Когда нужно идти на interview — приходится вспоминать, что было год назад
- Конкуренты с свежим резюме побеждают на рынке

РЕШЕНИЕ:
- Подключаете LinkedIn профиль (OAuth)
- Сервис автоматически вытягивает: новые скиллы, новые позиции, рекомендации
- Раз в неделю отправляет письмо: "Вот что нового в вашем профиле, добавить в резюме?"
- Генерирует улучшенное резюме в PDF (с ATS-оптимизацией)
- Ведёт историю версий резюме

МОНЕТИЗАЦИЯ:
- $9.99/месяц (базовый план)
- $19.99/месяц (+ cover letter generator, + interview tips)
- Free tier (просмотр только, обновления 1x месяц)

ЦЕЛЕВАЯ АУДИТОРИЯ:
- IT специалисты (разработчики, QA, DevOps, Data Engineers)
- Возраст: 25-50
- Боль: "Я не помню, как описать свой проект из 2023 года на интервью"

NO-CODE STACK:
- Backend: Make.com (LinkedIn API интеграция)
- PDF generator: Zapier + DocuSeal
- Email: Mailchimp
- Хранилище резюме: Google Drive / Dropbox API

РЕАЛИСТИЧНО:
- MVP за неделю (базовая версия)
- Целевая аудитория: 10,000+ IT специалистов только в Беларуси/Литве
- Month 3: 100-200 пользователей = $1000-2000/месяц
- High retention (люди юзят месяцы подряд)
